# 3. Hashed per-Python locks; torch pinned via a constraint
Status: accepted (2026-10-07)

Decision: `requirements/lock-{gpu,cpu}-linux-pyXY.txt` generated by `uv pip compile --generate-hashes`; torch 2.6.0 is held
by `torch-constraint.txt` so it resolves together with triton and CUDA libs. CI installs CPU torch first, then the CPU lock.
Consequences: reproducible, tamper-evident installs; torch 2.6.0 has known advisories (see SECURITY.md) until upgraded;
Windows/macOS are not locked.
